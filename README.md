# Lottery-App
The Lottery Management Web Application is a lightweight, responsive application built with HTML, CSS, Bootstrap 5, and JavaScript. It allows users to create and manage multiple lottery events without a backend, using the browser’s localStorage to securely save data even after refreshing or closing the browser.
